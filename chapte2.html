2. Number System and Conversion Boolean Logic

A number system is a mathematical method for representing quantities and values using a specific set of symbols and rules. Number Systems in ComputingComputers use different base systems to store and process data. You can learn more about digital representations through the Britannica Number System Guide.Binary (Base-2): Uses only 0 and 1; the core language of computers.Decimal (Base-10): Uses digits 0 through 9; the standard system humans use daily.Octal (Base-8): Uses digits 0 through 7; used in computing as shorthand for binary.Hexadecimal (Base-16): Uses digits 0–9 and letters A–F; used in low-level programming
